Default
Detect

The default IDE opens on a single click; the badge on a project picks another. Tabs keep projects in one window — real tabs on macOS. Linux has none, so a project is attached to the window already open instead: it joins it as another root, and what was open stays open. Off, every project gets its own window and naeasy switches between them.

Fast-start base branches

Click a branch to make it the default, ✕ removes it. The branch button on a project branches from the base (freshened from origin) and opens the IDE.

Layout

Size
