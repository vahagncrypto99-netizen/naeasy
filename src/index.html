⌘ naeasy
IDEs & settings
Editors / IDEs
Default

The default IDE is used on a single click. Click the badge on a project to pick a different one. ✕ removes the IDE selected above.

Global shortcut

Toggles the window from anywhere. Click, then press your combo (a modifier + one key).

Projects

Keeps projects as tabs of one IDE window (JetBrains IDEs; needs Accessibility). Off — a new window per project.

Fast-start base branches
Default

⚡ on a project creates a branch from the base (freshened from origin) and opens the IDE. Each project can remember its own base.

Startup
App

To uninstall: quit the app here (or via the menu-bar icon), then drag naeasy from Applications to the Trash — or run ./uninstall.sh.
